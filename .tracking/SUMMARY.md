# Summary - Sistema de Templates Storefront (Backoffice)

## Objetivo
Crear interfaz en el backoffice para que los usuarios OWNER puedan seleccionar el template de su storefront.

## Decisiones Técnicas
- Usar React Query para obtener/actualizar configuración
- Selector visual con cards de cada template
- Indicador del template activo
- Requiere permisos de OWNER
